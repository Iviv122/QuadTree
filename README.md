# QuadTree
Web implementation of many to many collision using Quadtree data structure

## Features
- minimal depth change
- change amount of particles/balls
- threshold change for splitting

## Tech stack

- p5js
- pnpm
- vite

## local install

```
git clone https://github.com/Iviv122/QuadTree
cd QuadTree
pnpm install
pnpm run dev
```
